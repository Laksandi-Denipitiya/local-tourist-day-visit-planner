# Local Tourist Day-Visit Planner

## Technologies
- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- MySQL
- XAMPP

## Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into:
   C:\xampp\htdocs\
4. Create a database named:
   tourist_planner
5. Import:
   sql/database.sql
6. Open:
   http://localhost/local-tourist-planner/

## Admin
Access:
http://localhost/local-tourist-planner/admin/login.php
